# Installing `RASPA` from Source
\page installing_from_source Installing from Source

To install the native executable from this branch, follow the [Linux installation guide](https://github.com/Chung-Research-Group/RASPA3-MBX/blob/mbx/INSTALLATION.md). It includes the matching CMake preset, dependency versions and an installed calculation.

For upstream release builds on other platforms, see the [upstream source guide](https://github.com/iRASPA/RASPA3/blob/main/docs/manual/installing_from_source.md).
